# Note:    This is the post-patch analog of the freedev003 (Intel Tiger
#          Lake i9-11950H) baseline.  The wave-3 / wave-5 patches should
#          not affect non-nested paths, so this baseline represents the
#          post-patch expected floor for non-nested guests on the AMD

#          work (--cpu-max-prime=20000) so the inverse relationship
#          (CPU work / events-per-second) holds across hosts.
#
# Metric note: "events_per_second" is sysbench's primary throughput
# metric; "total events" is the integral over the --time=10s run.  The
# default --time=10 is constant across runs so the wall-clock line is
# always ~10.000s and carries no signal.

# captured on an Intel Tiger Lake i9-11950H with mean=2.1133s (single-

# baseline's throughput into equivalent CPU-work seconds via
# 1/events_per_second * (--time=10s * --threads) yields:
