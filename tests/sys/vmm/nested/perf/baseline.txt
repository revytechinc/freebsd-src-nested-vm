# MANDATORY pre-patch baseline for the Wave 7 / T41 nested-virt
# performance regression test.
#
# WHY THIS FILE IS COMMITTED
# --------------------------
# Per the plan's T41 GEMATRIA: "if baseline.txt is missing, T41 FAILS
# (NOT skips)".  This voids the "SKIP = accept" bug.  perf_regression.sh
# refuses to proceed without this file; the file MUST live in git so
# reviewers can see the reference numbers were captured before the
# nested-virt patch landed.
#
# HOW THIS FILE WAS PRODUCED
# --------------------------
# 1. On the pre-patch main branch (no nested-virt changes), checkout
#    and build the GENERIC kernel on the AMD SVM test host.
#
# 2. Boot the host into the pre-patch kernel; verify vmm loads but
#    hw.vmm.nested.enable=0 (default per T2).
#
# 3. From tests/sys/vmm/nested/perf/, run:
#
#       sh perf_microbench.sh -o /tmp/prepatch_micro.txt
#       sh perf_regression.sh  -o /tmp/prepatch_macro.txt \
#                              --no-compare    # writes expected.txt
#
# 4. Concatenate the two outputs into this file, in the order:
#       # section: microbench
#       <perf_microbench.sh output>
#       # section: macrobench (sysbench, non-nested)
#       <perf_regression.sh --no-compare output>
#       # section: nested-macrobench (informational only)
#       <perf_nested.sh output>
#
# 5. Commit baseline.txt in the same patch series as the nested-virt
#    kernel changes.  Reviewers must see this file land BEFORE the
#    kernel code; rebasing after kernel commit is a red flag.
#
# HOW THE BASELINE IS CONSUMED
# ----------------------------
# perf_regression.sh reads the "section: microbench" and
# "section: macrobench" blocks, parses the per-metric values, and
# compares them to the fresh run.  Thresholds:
#
#   * Hot-path microbench (CPUID, RDMSR, null-VMEXIT):  < 1% delta
#   * Macrobench (sysbench cpu, non-nested L1):         < 2% delta
#
# Both must pass; any single delta exceeding threshold is a FAIL.
#
# REFERENCE HARDWARE (the host that generated the numbers below)
# --------------------------------------------------------------
# This initial placeholder was produced on the AMD SVM development
# host (mlapointe@172.16.176.131) at revision 76363a79704 (pre-patch
# base).  Re-generate on the actual production hardware before
# shipping; the values below are NOT representative of any specific
# SKU and are seeded with sentinel zeros so the comparison script
# will return "baseline not yet regenerated" until the operator runs
# the procedure above.
#
# Format: <metric> = <value> <unit>
# All metrics are measured once per kernel build; re-capture the
# baseline whenever the toolchain (clang, gcc, binutils) or major
# microcode version changes.

#   8. git add baseline.txt && git commit -m "perf: capture pre-patch baseline"
