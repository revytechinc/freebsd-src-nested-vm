# Format (one vector per line):
#   ID|EXIT_REASON|EXIT_QUAL|EXIT_INT|EXIT_GUEST_PHYS|MASK|CATEGORY
#
#   ID              - stable identifier (MUST NOT change once committed)
#   EXIT_REASON     - decimal exit reason (1-78 for AMD SVM; 1-77 for Intel VMX)
#   EXIT_QUAL       - hex exit qualification register
#   EXIT_INT        - decimal interrupt info (if applicable)
#   EXIT_GUEST_PHYS - hex guest physical address (if applicable)
#   MASK            - 32-bit hex mask applied to exit reason only
#   CATEGORY        - MUST_PASS | KNOWN_DIFF
#
# CATEGORY semantics:
#   MUST_PASS   - L2 must observe this exit reason with the expected
#                 qual/int/guest_phys when the L1 hypervisor triggers
#                 the corresponding operation. Architectural correctness.
#   KNOWN_DIFF  - documented in PARITY.md; test passes if vector is
#                 present, exact value comparison is skipped
#
# Source: vectors are derived from
#   - AMD APM Vol. 2, SVM Intercept Exit Codes
#   - Intel SDM Vol. 3, VM-Exit Reasons
#   - Hyper-V TLFS 7.8 (hypercall exit)
# No values are copied from KVM source code.
#
