# Format (one vector per line):
#   ID|LEAF|SUBLEAF|MASK|EXPECTED|ORDER|CATEGORY
#
#   ID          - stable identifier (MUST NOT change once committed)
#   LEAF        - CPUID leaf (hex)
#   SUBLEAF     - CPUID subleaf (hex, often 0)
#   MASK        - 32-bit hex mask; only bits set in MASK are compared
#   EXPECTED    - expected value after masking (one or more fields)
#   ORDER       - register comparison order:
#                   EAX               - EAX only
#                   EAX_EBX_ECX_EDX   - all four (EAX, EBX, ECX, EDX)
#                   EAX_ECX           - EAX, ECX (for leaf 4)
#   CATEGORY    - MUST_PASS | KNOWN_DIFF
#
# CATEGORY semantics:
#   MUST_PASS   - L2's view must match expected (architectural correctness)
#   KNOWN_DIFF  - documented in PARITY.md; test passes if vector is
#                 present, exact value comparison is skipped
#
# Adding a new MUST_PASS without updating PARITY.md is a hard policy
# violation. KNOWN_DIFF count must equal the allowlist in PARITY.md.
#
# Source: vectors are derived from
#   - Intel SDM Vol. 2A, CPUID instruction reference
#   - AMD APM Vol. 3, CPUID Specification
#   - Hyper-V TLFS 7.8.2
#   - AMD64 ABI, section 3.3
# No values are copied from KVM source code.
#
