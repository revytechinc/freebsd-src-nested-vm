# Format (one vector per line):
#   ID|FIELD_NAME|ENCODING|BITS|EXPECTED_VALUE|MASK|CATEGORY
#
#   ID              - stable identifier
#   FIELD_NAME      - architectural VMCS12 field name (Intel SDM Vol. 3,
#                     Appendix B)
#   ENCODING        - hex field encoding (high 16 bits = width, low 16 =
#                     index, per Intel SDM 24.11.2)
#   BITS            - decimal number of significant bits in field
#   EXPECTED_VALUE  - expected L2-viewable value (with MASK applied)
#   MASK            - bitmask applied before comparison
#   CATEGORY        - MUST_PASS | KNOWN_DIFF
#
# CATEGORY semantics:
#   MUST_PASS   - VMCS12 field must round-trip L1<->L2 unchanged
#   KNOWN_DIFF  - documented diff vs KVM in PARITY.md
#
# Source: Intel SDM Vol. 3, Appendix B (VMCS field encoding)
# No values copied from KVM source.
#
